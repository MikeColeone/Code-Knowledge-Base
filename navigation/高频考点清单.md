# 高频考点清单

## JS 基础

- 执行上下文、作用域链、闭包。
- 原型、原型链、继承方案。
- `this`、`call`、`apply`、`bind`。
- 事件循环、宏任务、微任务、`async/await`。
- Promise 原理、异常穿透、链式调用。
- 深拷贝、浅拷贝、类型判断。
- 垃圾回收、内存泄漏、排查方式。

## 浏览器

- 输入 URL 到页面展示。
- 浏览器进程和线程模型。
- 渲染流程、重排、重绘、合成层。
- 缓存策略、强缓存、协商缓存。
- 跨域、同源策略、CORS、JSONP。
- XSS、CSRF、点击劫持、防御方案。

## CSS 和布局

- 盒模型、BFC、层叠上下文。
- Flex、Grid、常见居中方案。
- 两栏、三栏、圣杯、双飞翼布局。
- 移动端适配、响应式、1px 问题。
- CSS 性能优化和动画优化。

## TypeScript

- 基础类型、联合类型、交叉类型。
- 泛型、条件类型、映射类型。
- 类型收窄、类型守卫。
- 工具类型实现。
- 类型体操和工程实践边界。

## 计算机通用技能

- HTTP 和 HTTPS、TCP 和 UDP。
- TCP 三次握手、四次挥手、`TIME_WAIT`。
- DNS 解析、CDN、反向代理、缓存链路。
- 进程、线程、协程、进程间通信。
- 用户态、内核态、系统调用、内存管理。
- 常见数据结构、复杂度、哈希表、堆、队列。
- 数据库索引、事务、隔离级别、锁。
- 浏览器进程线程模型、主线程互斥、长任务影响。
- 缓存链路、DevTools 缓存排障、发布后资源更新问题。

## React

- Fiber 架构和可中断渲染。
- Hooks 原理和使用规则。
- `useEffect`、`useMemo`、`useCallback`。
- React Diff、key、调度和批处理。
- 状态管理、组件通信、性能优化。

## Vue

- 响应式原理。
- 模板编译和虚拟 DOM。
- 组件通信和生命周期。
- `computed`、`watch`、`nextTick`。
- Vue2 和 Vue3 差异。

## 工程化

- Webpack 构建流程、Loader、Plugin。
- Tree Shaking、代码分割、缓存优化。
- Vite/Rspack 等现代构建工具差异。
- Git 分支管理、冲突处理、回滚策略。
- CI/CD、发布流程、灰度和回滚。

## 场景题

- 首屏性能优化。
- 大数据量列表渲染。
- 大文件上传和断点续传。
- 前端监控、错误上报、性能指标。
- 登录鉴权、扫码登录、单点登录。
- 微前端拆分、通信、样式隔离、部署。

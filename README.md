# 前端面试仓库

这是一个面向前端面试准备的总结仓库，目标是把零散知识、题型训练和可运行示例收拢到一套清晰结构里，方便复习、查漏和模拟输出。

## 目录导航

- [`navigation/`](./navigation/README.md)：复习路线、索引和仓库入口
- [`knowledge/`](./knowledge/README.md)：知识点正文，按基础、框架、工程化、架构、Node.js 归档
- [`questions/`](./questions/README.md)：面试题输出，按手写题和场景题归档
- [`labs/`](./labs/README.md)：可运行 demo 和单点验证代码
- [`templates/`](./templates/)：手写题、场景题、知识点模板

## 推荐使用顺序

1. 先看 [`navigation/`](./navigation/README.md)，明确复习路线和索引入口
2. 再看 [`knowledge/`](./knowledge/README.md)，系统补齐知识主干
3. 然后刷 [`questions/`](./questions/README.md)，训练结构化表达和手写能力
4. 需要验证代码时，再进入 [`labs/`](./labs/README.md)

## 当前结构原则

- 顶层只保留面试准备真正会用到的入口
- `knowledge/` 只放知识正文
- `questions/` 只放题型输出
- `navigation/` 只做路线和索引
- 不再保留历史迁移目录和规划骨架

## 使用方式

```bash
git clone <repository-url>
cd interview-code-base
```

如果你要直接开始刷题，优先从 `navigation/`、`questions/handwrite/` 和 `questions/scenario/` 进入。

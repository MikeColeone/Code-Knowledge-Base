# 你对盒模型的理解

## 什么是盒模型

浏览器的渲染引擎会基于CSS基础盒模型也就是 `CSS basic box model` 将所有元素表示为一个个矩形的盒子，该盒子由：

- `content`:实际内容
- `padding`:内边距
- `border`:边框
- `margin`:外边距

## 盒子模型

基于 `box-sizing`控制：

1. 标准盒子模型：content-box（默认）
2. 怪异盒模型：border-box

前者的宽度高度 = width + padding + border + margin

后者的宽度高度 = width + margin

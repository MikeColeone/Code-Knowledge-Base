- display:none和visibility:hidden



---

### 1. `display: none`

* **元素完全不渲染** ，相当于从  **文档流中移除** 。
* 浏览器布局时，会当做这个元素不存在，所以不会占据任何空间。
* 子元素也不会渲染，事件也不会触发。

  👉 类似于“直接拿掉 DOM 节点”的效果（但 DOM 还在，只是没渲染）。

---

### 2. `visibility: hidden`

* **元素仍在文档流中** ，只是内容不可见。
* 占据的空间、位置、大小依然保留。
* 子元素也会隐藏（除非单独设置 `visibility: visible`）。
* 不会触发交互事件（点击、hover 等）。

  👉 类似于“透明度为 0，但还占坑”的效果。

---

### 3. 区别总结

| 属性                   | 是否占据空间 | 是否渲染子元素 | 是否可交互  |
| ---------------------- | ------------ | -------------- | ----------- |
| `display: none`      | ❌ 不占空间  | ❌ 不渲染      | ❌ 不可交互 |
| `visibility: hidden` | ✅ 占空间    | ✅ 结构保留    | ❌ 不可交互 |

---

### 4. 补充对比：`opacity: 0`

* 和 `visibility: hidden` 类似： **占据空间** 。
* 但不同的是：元素依然  **可交互** （能点到）。

👉 所以这三个属性可以这样理解：

* `display: none` → 元素不存在。
* `visibility: hidden` → 元素存在，占位但看不见。
* `opacity: 0` → 元素存在，看不见，但仍能操作。

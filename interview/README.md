# 面试专题

该目录直接面向面试准备，包含手写题、场景题、系统设计和项目复盘。

## 目录说明

- [handwrite](./handwrite/)：高频手写题，按题型分类。
- [scenario](./scenario/)：业务场景题和解决方案。
- [system-design](./system-design/)：前端系统设计题，适合中高级面试。
- [project-review](./project-review/)：项目复盘、亮点包装和追问准备。

## 使用建议

- 手写题先追求正确性，再补复杂度和边界情况。
- 场景题优先训练结构化表达，不要只背结论。
- 项目复盘要准备“背景、问题、方案、结果、复盘”。

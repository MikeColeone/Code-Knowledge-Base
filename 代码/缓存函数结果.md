```js
function cacheWrapper(func: Function) {

  // 你的代码

}
```

比如 function func1() { ... };

执行了  const cachedFunc1 = cacheWrapper(func1); 后

用 cachedFunc1(argsA) 得到结果 result，再次执行 cachedFunc1(argsA) 后，可以立刻返回之前的结果 result

# 前端知识库

这里是本仓库的核心模块，面向前端开发、技术沉淀和面试准备。当前目录按照“学习路径 + 知识领域 + 面试题型 + 可运行代码”组织，方便从系统复习、定向查漏、面试突击和日常查询四种场景进入。

## 如何使用

- 系统复习：先看 [前端面试复习路线](./00-roadmap/前端面试复习路线.md)，按阶段推进。
- 高频查漏：使用 [高频考点清单](./00-roadmap/高频考点清单.md)，快速定位薄弱点。
- 八股准备：从 [八股题索引](./00-roadmap/八股题索引.md) 进入基础、计算机通用技能、框架、工程化专题。
- 手写训练：从 [手写题索引](./00-roadmap/手写题索引.md) 进入异步、数组、函数、算法、布局等题型。
- 场景题准备：从 [场景题索引](./00-roadmap/场景题索引.md) 进入性能、稳定性、安全、工程化和业务方案。
- 结构治理：优先从各模块 `README.md` 和索引进入，正式内容逐步沉淀为单题文件。

## 目录结构

```text
front-knowledge-base/
  00-roadmap/       # 复习路线、考点清单、题型索引
  01-foundation/    # JS、TS、HTML、CSS、浏览器、计算机通用技能
  02-framework/     # React、Vue 框架原理与实践
  03-engineering/   # Webpack、Node.js、Git 等工程化能力
  04-architecture/  # 微前端、性能、安全、监控等架构专题
  05-interview/     # 手写题、场景题、系统设计、项目复盘
  06-code-lab/      # 可运行的 JS/TS/HTML 代码片段
  templates/        # 统一题目模板
```

## 模块说明

- [00-roadmap](./00-roadmap/)：负责回答“我应该怎么复习、先看什么、哪些高频”。
- [01-foundation](./01-foundation/)：沉淀前端基础，包括语言、浏览器、HTML、CSS、TypeScript 和计算机通用技能。
- [02-framework](./02-framework/)：沉淀 React、Vue 等框架原理、源码思路和实践题。
- [03-engineering](./03-engineering/)：沉淀构建、依赖、脚手架、Git、Node.js 和工程协作。
- [04-architecture](./04-architecture/)：沉淀复杂应用架构，如微前端、性能优化、稳定性、监控和安全。
- [05-interview](./05-interview/)：沉淀直接面向面试的题型，包括手写题、场景题、系统设计和项目复盘。
- [06-code-lab](./06-code-lab/)：沉淀可以直接运行、调试和验证的代码片段。
- [templates](./templates/)：提供题目、场景题、手写题的统一写作模板。

## 内容沉淀规范

- 一道题只解决一个核心问题，避免多个主题混在同一篇笔记中。
- 每篇面试题建议包含“题目、核心答案、深入解释、追问、易错点、关联题”。
- 每篇手写题建议包含“题目、思路、代码、复杂度、边界情况、追问”。
- 每篇场景题建议包含“背景、目标、方案、权衡、异常处理、可观测性、追问”。
- 新增内容优先补充到对应索引，保证从 README 可以逐层找到。
- `note.md` 只作为问题池或临时记录，正式答案优先进入符合 `kebab-case` 命名的独立文件。

## 推荐复习顺序

1. 先过 `01-foundation`，保证 JS、浏览器、HTML、CSS、TS 以及计算机通用技能基础稳。
2. 再过 `02-framework`，重点理解 React/Vue 原理和常见追问。
3. 然后过 `03-engineering`，补齐构建、Git、Node.js 和工程协作能力。
4. 接着过 `04-architecture`，准备性能、安全、微前端、监控等高级问题。
5. 最后集中刷 `05-interview`，用手写题和场景题模拟真实面试输出。

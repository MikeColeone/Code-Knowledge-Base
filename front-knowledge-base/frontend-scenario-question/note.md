# 现代前端应用大都是SPA应用，基本一个路由对应着一个页面，本地路由切换浏览器也不会刷新，现在需要实现一个可以统计前端页面PV的SDK，这个SDK可以被添加到各种类型的前端工程中都可以正常工作，思路是什么？

首先能意识到URL发生变化且浏览器不刷新的情况都有啥：

1. url hash 改变，
2. 通过 history.pushState 改变 url

方案：

1. 针对 hash 变化，可以直接监听 hashChange 时间
2. 针对 history.pushState 导致的变化，由于当前浏览器并没有相应的事件通知，无法直接监听，本题的难点就在此！  思路：可以重写 pushState 覆盖默认 history.pushState 方法(覆盖前保存原始方法)，然后在覆盖方法中统计PV后再调用原始方法即可。

# TCP 三次握手和四次挥手

## 核心答案

三次握手用于确认双方的收发能力正常，并同步初始序列号；四次挥手用于双方分别关闭各自方向的数据传输。

## 三次握手

1. 客户端发送 `SYN`。
2. 服务端返回 `SYN + ACK`。
3. 客户端再发 `ACK`，连接建立。

## 四次挥手

1. 一方发送 `FIN`，表示自己没有数据要发了。
2. 对方回 `ACK`，确认收到。
3. 对方处理完剩余数据后再发 `FIN`。
4. 最后另一方回 `ACK`，连接关闭。

## 前端面试切入点

常见追问是为什么不是两次握手、为什么挥手通常是四次、`TIME_WAIT` 有什么作用。

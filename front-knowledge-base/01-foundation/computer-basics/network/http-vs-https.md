# HTTP 和 HTTPS 的区别

## 核心答案

HTTP 是明文传输协议，HTTPS 是在 HTTP 之上加入 TLS 加密层的安全通信方案。HTTPS 解决的核心问题是传输内容可能被窃听、篡改和冒充。

## 关键点

- HTTP 默认端口是 `80`，HTTPS 默认端口是 `443`。
- HTTPS 通过证书校验服务端身份，避免中间人伪装。
- HTTPS 建立连接时会多一次 TLS 握手，因此初始阶段开销更高。
- HTTPS 一旦连接建立，现代 TLS 配合会话复用后，性能损耗通常可接受。

## 前端面试切入点

前端常会继续被追问 Cookie 的 `Secure`、`HttpOnly`、HSTS、混合内容、证书失效和接口抓包风险。

# 前端体系

这里承接用户可见层相关的知识，包括前端基础、框架、渲染和工程能力。

## 目录说明

- [`foundation/`](./foundation/)：HTML、CSS、JavaScript、TypeScript、Browser 与计算机基础
- [`framework/`](./framework/)：React、Vue 及相关原理
- [`engineering/`](./engineering/)：构建、打包、前端工程能力

## 当前说明

这次迁移以保留原有内容为优先，所以 `foundation/` 里仍保留了 `computer-basics` 等偏通用主题。后续如果你要继续细拆，可以再把网络、操作系统、数据库等内容逐步抽到 `backend/` 或 `architecture/`。

## 推荐阅读顺序

1. `foundation/`
2. `framework/`
3. `engineering/`
